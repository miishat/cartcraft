# CartCraft Rewrite Roadmap

Spec: [2026-10-01-cartcraft-rewrite-design.md](../specs/2026-10-01-cartcraft-rewrite-design.md)

The spec covers five subsystems. Each gets its own plan, and each plan ends with working, tested software. Plans are written just before they are executed, so each one builds on the real code from the plans before it.

| # | Plan | Spec sections | Delivers | Depends on | Status |
|---|---|---|---|---|---|
| 1 | [Domain core](2026-10-01-plan-1-domain-core.md) | 4.1, 5, 10.1 | `src/domain/`: parse, itemKey, scale, merge, format, aisles, yield, JSON-LD, with 196 tests | none | Written, dry-run verified |
| 2 | [Data and app shell](2026-10-01-plan-2-data-and-app-shell.md) | 3, 4.2, 6, 9.1, 9.2, 10.2 | Dexie schema and use cases, backup (export, share, import, undo), Tailwind install, React Router, all screens without LLM or URL import, old root UI removed; 269 tests total | 1 | Written, dry-run verified |
| 3 | URL import function | 7, 10.2 | `functions/api/import.ts` with SSRF guards, HTMLRewriter extraction, `mode: "text"`, rate limiting; client `services/urlImport.ts` and the add-recipe flow wiring; Vite proxy to `wrangler pages dev` | 1, 2 | Not written |
| 4 | LLM layer | 8, 10.2 | Provider config, OpenAI-compatible client, the four jobs with Zod validation, Settings key and test connection, UI buttons | 1, 2 (3 for URL fallback) | Not written |
| 5 | PWA, security and deploy | 9.3, 9.4, 9.5, 11 | vite-plugin-pwa with update prompt, `_headers` with CSP generated from providers, self-hosted fonts, iOS install banner, wake lock, Playwright e2e, Cloudflare Pages deploy, acceptance criteria run | 2, 3, 4 | Not written |

Open items carried into later plans:

- Plan 3: confirm whether the Workers rate-limit binding is available to Pages Functions on the free plan; otherwise use the in-memory fallback from spec 7.
- Plan 5: compare Cloudflare Pages with Netlify before the first public deploy (only `functions/api/import.ts` changes).
