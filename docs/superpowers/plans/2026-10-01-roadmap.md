# CartCraft Rewrite Roadmap

Spec: [2026-10-01-cartcraft-rewrite-design.md](../specs/2026-10-01-cartcraft-rewrite-design.md)

The spec covers five subsystems. Each gets its own plan, and each plan ends with working, tested software. Plans are written just before they are executed, so each one builds on the real code from the plans before it.

Decisions recorded while writing Plans 3 to 5:

- Rate limiting: the Workers rate-limit binding is not listed for Pages Functions, so the import function uses an in-memory per-isolate limiter (spec 7 fallback).
- The Pages Function adapter is verified with `wrangler pages dev` rather than unit tests, because `@cloudflare/vitest-pool-workers` requires Vitest 4.
- Provider defaults (2026-10-01): DeepSeek `deepseek-flash`, OpenRouter `deepseek/deepseek-v4.1-flash`, OpenAI `gpt-6-luna`, Groq `openai/gpt-oss-20b`.
- Hosting (2026-10-01): Cloudflare Workers with static assets instead of Pages, because Cloudflare now recommends Workers for new projects. This replaces the Netlify comparison. The import endpoint moved to `worker/index.ts` and uses the Workers rate-limit binding (the in-memory limiter remains as a fallback).
- Fonts: the system font stack, so there are no web fonts to self-host.
- `@vite-pwa/assets-generator` stays on 1.x until vite-plugin-pwa accepts 2.x as a peer.

Open items:

- Known parser limitation: "1 lb boneless, skinless chicken breast" splits at the first comma (item "boneless"); the review table lets the user fix it. Revisit if it shows up often.
